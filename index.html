How This Relates to Models of Computation

Q = {Idle, Cruise, Follow, Stop, PrepareLC, LaneChange, EmergencyStop}
q₀ = Idle
Σ = {engage, vehicleAhead, roadClear, stopRequired, resume, laneChangeRequest, laneSafe, laneUnsafe, laneChangeComplete, hazard, reset}
δ : Q × Σ → Q · Example: δ(Cruise, vehicleAhead) = Follow

This is a finite-state controller/transducer rather than purely a language-accepting DFA. In robotics, states represent behavioral modes and transitions are triggered by events or conditions. Outputs depend on the current state, approximately Moore-style: Output = f(State). Unlisted events leave the state unchanged. Event priority, if evaluated together: hazard > stopRequired > laneChangeRequest > vehicleAhead > continuation events.
